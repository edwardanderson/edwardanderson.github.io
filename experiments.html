Linked Art Reader

The Linked Art Reader is an experimental web application for exploring content served through Linked Art APIs.

It uses the Linked Art Model 1.0 documentation's page layout as a template for content that's dynamically retrieved as the user navigates through the data. Every hyperlink has two targets: a link to the content to be displayed in the Reader, and an arrow for navigating to the source.

Code is largely AI-generated, but is available in the GitHub repository.

Here's a brief video demoing the Reader by exploring Yale University's Linked Art data for Grimshaw's 1878 painting Whitby and some related records.

RDFS Pydantic

Would it be useful to generate data contracts from arbitrary RDFS ontologies? RDFS Pydantic is an exploratory prototype. 

                
                    @prefix ex: <http://example.org/> .
                    @prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
                    @prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .

                    ex:Example a rdfs:Class ;
                        rdfs:label "An Example class"
                        rdfs:comment "Useful for examples" .

                    ex:name a rdf:Property ;
                        rdfs:domain ex:Example ;
                        rdfs:range rdfs:Literal

                    ex:example_property a rdf:Property ;
                        rdfs:domain ex:Example ;
                        rdfs:range ex:Example .
                
            
                
                    from pydantic import BaseModel, Field

                    class Example(BaseModel):
                        """
                        An Example class .

                        Useful for examples.
                        """
                        example_property: Example | list[Example] = Field(default_factory=list)
                        name: str | list[str] = Field(default_factory=list)

Nested Triple Trees Language

Nettle is a specification for a compact, human-friendly concrete syntax for RDF. It expresses triples as indented trees so that related resources may be visually grouped.

All the Art in the Rijksmuseum

Responding to Generous Interfaces for Digital Cultural Collections, what if you could look at every single object in the Rijksmuseum? How long would that take? Scrolling by at a rate of one every fifth of a second viewing the 400,000 photographed objects would take about four hours. Or until you run out of disk space.

A scrolling conveyor of almost all the photographed artworks and objects in the Rijksmuseum. Organised by visual similarity, it starts from the oldest item in the collection – a fossilised Dutch mollusc – and spools through tens of thousands of photographs, plates, tea cups, tiles, swords, spoons, clocks, vases, prints, portraits, chairs, keys, candlesticks, drawings, documents, sketches, maps and more...

You can watch this for four hours on YouTube.
